# v0.3a — SEC EDGAR Fundamentals + Deep US Backtest

**Date:** 2026-07-12 · **Status:** Approved (autonomous mode)
**Why:** Backtest findings identified statement depth (~5y via Yahoo) as the
binding constraint on calibrating the quality/growth thesis. SEC EDGAR's
`companyfacts` XBRL API provides 10-15+ years of US statements, free and
official, **with per-fact filing dates** — upgrading point-in-time gating from
the +90-day heuristic to exact first-public dates.

## Components

1. **Model**: `FinancialHistory.filed: dict[int, date]` (optional, default {})
   — year → date the year's annual data first became public.
   `truncate_financials` prefers real filed dates; falls back to FY-end + 90d.
2. **`data/edgar.py`**:
   - ticker → CIK via `https://www.sec.gov/files/company_tickers.json` (cached 30d).
   - `https://data.sec.gov/api/xbrl/companyfacts/CIK{cik:010d}.json` (cached 7d).
   - Parse rule: us-gaap tags via ordered TAG_MAP fallbacks; **flow** facts
     require duration 340-390 days (annual), **instant** facts use `end` only;
     year key = calendar year of `end`; per year keep the earliest-filed value
     (the original filing — restated values would leak the future);
     `filed[year]` = that filing date. Requires descriptive User-Agent header
     (SEC policy), ≤10 req/s (we do ~1/ticker, cached).
   - Known gaps documented: no EBITDA tag (metrics degrade to None honestly);
     total_debt approximated from long-term debt tags.
3. **`data/composite.py`**: `CompositeProvider(fundamentals, market)` —
   EDGAR statements + Yahoo info/prices behind the same `DataProvider` protocol.
4. **CLI**: `--fundamentals edgar` flag on `analyze` and `backtest` (US tickers).
5. **Universe**: curated `us-largecap60` across sectors for a powered sample.
6. **Deep backtest**: multibagger + investment scores, cutoffs 2018-2024
   (7 annual), horizons 365d and 730d, on us-largecap60.

## Testing
Fixture-based: miniature companyfacts JSON → FinancialHistory (values, year
keying, original-filing preference, filed dates); CIK resolution from fixture
JSON; filed-aware truncation honored by harness (no leakage); composite
provider routes calls. Live checks marked network.

## Out of scope (still v0.3+)
Indian XBRL filings, macro/policy/news modules, promoter pledging.
