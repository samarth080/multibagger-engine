# P2.2 — Prediction Ledger + Calibration Engine

**Date:** 2026-07-13 · **Status:** Approved (autonomous mode, Phase 2)
**Goal:** The scientific spine. Every checkable claim the platform makes is
recorded as a prediction with a stated confidence, resolved against reality
when due, and scored for calibration. Future modules are judged by this ledger.

## What counts as a prediction (deterministic, machine-checkable)

From every analysis, the thesis's falsifiable assumptions become 1-year
predictions: *"ROCE >= 15% will still hold at FY+1"* with
`confidence = historical_support`. Also: *"classification will still be X"*.
These are exactly the claims the thesis stakes its confidence on — now they
are accountable.

(Return/price predictions are deliberately NOT emitted: backtests show no
validated return edge, and a ledger must not launder unvalidated claims into
implied forecasts. If a future module earns a return edge, its predictions
join the ledger then.)

## Components

1. **Models** (`models/prediction.py`): `Prediction(ticker, made_on, due_on,
   kind, statement, confidence, source)` + `Outcome(resolved_on, actual,
   correct)`. Kinds: `assumption_holds`, `classification_stable`.
2. **Emission** (`thesis/predictions.py`): `emit_predictions(thesis, as_of) ->
   list[Prediction]` — pure.
3. **Ledger** (`storage.py`): `save_predictions`, `due_predictions(as_of)`,
   `record_outcome`, `resolved_predictions()`. Append-only; never edited.
4. **Resolution** (`thesis/predictions.py`): `resolve(prediction, thesis_now)
   -> Outcome` — re-derive the same assumption from data as of `due_on` and
   check truth. Uses the standard pipeline (or PIT harness for retro runs).
5. **Calibration** (`thesis/calibration.py`): reliability table (confidence
   buckets -> observed frequency), **Brier score**, and per-kind breakdown.
   `mbe calibration` CLI + section on the web home page.
6. **Retro-calibration** (`scripts/retro_calibration.py`): emit at historical
   cutoffs via the PIT harness (US small-caps 2018-2023 + India 2021-2023),
   resolve each against the following year's PIT data, produce the first real
   calibration report TODAY.

## Validation (right to exist)

P2.2 is measurement infrastructure; its proof is the retro-calibration run
producing a real reliability table on hundreds of resolved predictions. Bonus
decision rule: if stated confidences are badly miscalibrated (|observed -
stated| > 15pp in the well-populated buckets), document it and add a
data-derived correction — that would be the first *earned* recalibration in
the project.

## Testing
Hand-computed Brier anchors; bucket table math; emission determinism;
resolution truth-checking on synthetic fixtures; ledger round-trip +
append-only behavior; due-date filtering.
