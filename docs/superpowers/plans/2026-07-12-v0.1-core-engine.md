# Multibagger Engine v0.1 Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Working vertical slice: ticker → data → fundamental/technical/valuation/risk analysis → explainable scores with confidence → institutional markdown report + universe screener.

**Architecture:** Modular Python package (src layout). Protocol-based data connectors (Yahoo first) with on-disk cache. Analysis engines are pure functions over pydantic models / DataFrames. Table-driven scoring with evidence trails. Jinja2 markdown reports. Typer CLI.

**Tech Stack:** Python 3.12 (uv), pandas, numpy, yfinance, pydantic v2, typer, rich, jinja2, pytest.

### Task 2: Domain models

**Files:** `src/mbe/models/{company,analysis,scoring}.py`, `tests/test_models.py`

- `CompanyInfo`: ticker, name, exchange, currency, sector, industry, market_cap, float_shares, shares_outstanding, insider_pct, institution_pct, beta, description. All Optional except ticker.
- `FinancialHistory`: annual statements as `dict[str, dict[int, float | None]]` keyed by canonical field → year; canonical fields: revenue, gross_profit, operating_income, ebitda, net_income, interest_expense, total_assets, total_equity, total_debt, cash, current_assets, current_liabilities, cfo, capex, fcf, shares_diluted, dividends_paid. Method `years()` sorted asc; `series(field) -> list[(year, value)]` skipping None.
- `PriceHistory`: wraps a DataFrame (open/high/low/close/volume, DatetimeIndex); pydantic `arbitrary_types_allowed`.
- Analysis models: `FundamentalMetrics`, `TechnicalState`, `ValuationResult` (bear/base/bull fair values, implied_growth, margin_of_safety, expected_cagr_5y), `RiskAssessment` (flags: list[RiskFlag(code, severity, detail)], score 0-100 where high=risky). All metric fields `float | None`; each model has `completeness: float` (0-1).
- Scoring models: `Evidence(metric, value, benchmark, points, weight, rationale)`, `PillarScore(name, score, confidence, evidence)`, `ScoreCard(ticker, investment_score, multibagger_score, confidence, pillars, hard_gate_failures, verdict)`.
- [ ] Tests: FinancialHistory.series skips None and sorts; ScoreCard validates score ranges 0-100. Commit.

### Task 4: Fundamentals engine

**Files:** `src/mbe/analysis/fundamentals.py`, `tests/test_fundamentals.py`

`compute_fundamentals(fin: FinancialHistory, info: CompanyInfo) -> FundamentalMetrics`, pure. Metrics + formulas:
- CAGR(series, yrs): `(end/start)**(1/yrs) - 1`; requires start>0, end>0, else None. revenue_cagr_3y/5y, profit_cagr_3y/5y, fcf_cagr_3y.
- Margins (latest + 3y avg): gross, operating, ebitda, net. margin_trend = latest op margin − 3y-ago op margin.
- ROE = NI/equity; ROCE = EBIT/(equity+debt); ROIC ≈ EBIT·(1−tax 25%)/(equity+debt−cash). Latest + 3y avg.
- Leverage: debt_to_equity, net_debt_to_ebitda, interest_coverage = EBIT/interest.
- Liquidity: current_ratio.
- Cash: fcf_margin, cash_conversion = CFO/NI (3y sums), accruals_ratio = (NI−CFO)/total_assets (earnings quality; > 0.1 is a red flag).
- Dilution: share_count_cagr_3y.
- completeness = computed/attempted.
**Hand-computed test anchors:** revenue 100→200 over 5y ⇒ CAGR 14.87%; NI 10, CFO 14, assets 100 ⇒ accruals −0.04; EBIT 20, equity 60, debt 40 ⇒ ROCE 20%.
- [ ] TDD each group; verify Nones propagate (missing interest ⇒ coverage None, completeness < 1). Commit.

### Task 5: Technicals engine

**Files:** `src/mbe/analysis/technicals.py`, `tests/test_technicals.py`

`compute_technicals(prices: PriceHistory, benchmark: PriceHistory | None) -> TechnicalState`, pure pandas:
- SMA50/150/200, EMA21; price_vs_200sma pct; 200sma slope (20d change).
- RSI(14) Wilder; MACD(12,26,9) histogram sign; ATR(14) pct; Bollinger(20,2) %B; stochastic(14); ADX(14); OBV 20d slope; CMF(20).
- 52w high/low distance; trend_state ∈ {strong_up, up, sideways, down, strong_down} via Minervini-style template (price>150>200sma, 200sma rising, ≥30% above 52w low, within 25% of 52w high).
- relative_strength_63d = stock 63d return − benchmark 63d return.
- volatility_regime from ATR% terciles; avg_traded_value_20d (liquidity).
**Test anchors:** RSI of 14 straight gains = 100; constant series ⇒ ATR 0, RSI neutral behavior documented; SMA hand-check on 1..10.
- [ ] TDD with synthetic series (trend, flat, sine). Commit.

### Task 6: Valuation engine

**Files:** `src/mbe/analysis/valuation.py`, `tests/test_valuation.py`

`compute_valuation(fin, info, fund: FundamentalMetrics, price: float) -> ValuationResult`:
- Base FCF = max(latest fcf, 3y avg fcf); if fcf ≤ 0 fall back to NI·(1−dilution guard) with `fcf_proxy=True` note.
- Scenario DCF: growth years 1-5 g1, years 6-10 g1/2, terminal 4% (India) / 3% (US); discount 13% India / 10% US. bear/base/bull g1 = fund growth −40% / as-is capped 25% / +20% capped 35%.
- Reverse DCF: solve g1 (bisection 0-60%) s.t. DCF = market cap ⇒ implied_growth.
- Relative: current PE, EV/EBITDA, P/S vs own 3y median (from price history + fin) ⇒ premium/discount pct. PEG = PE / (profit_cagr_3y·100).
- margin_of_safety = base_fair/price − 1; expected_cagr_5y = (base_fair·(1+g_terminal)^0 ... simple: (base_fair/price)^(1/5)−1 + dividend yield.
**Test anchors:** FCF 100, g 10% 5y then 5%, term 4%, disc 13%, net cash 0 ⇒ deterministic PV, assert to 1e-6 vs hand-built loop in test; reverse DCF recovers g within 0.2pp on synthetic.
- [ ] TDD. Commit.

### Task 7: Risk engine

**Files:** `src/mbe/analysis/risk.py`, `tests/test_risk.py`

`assess_risk(fund, tech, val, info) -> RiskAssessment`. Rule table (code, severity 1-3, condition):
- SOLVENCY_DEBT d/e>2 (3) or >1 (2); COVERAGE ic<2 (3) or <4 (1); EARNINGS_QUALITY accruals>0.10 (3) or cash_conversion<0.6 (2); DILUTION share cagr>5% (2); NEGATIVE_FCF 3y fcf sum<0 (2); VALUATION_HOT implied_growth>30% (2), peg>3 (1); MICRO_ILLIQUID traded value < ₹1cr/day equiv (2); DRAWDOWN_VOL atr%>6 (1); GOVERNANCE_UNKNOWN insider/promoter data missing (1, info).
- risk_score = min(100, Σ severity·12); probability_of_permanent_loss bucket: low/<25, medium/<50, high.

### Task 8: Scoring engine

**Files:** `src/mbe/scoring/{benchmarks,pillars,engine}.py`, `tests/test_scoring.py`

- `benchmarks.py`: `THRESHOLDS: dict[str, list[tuple[float, int]]]` descending, e.g. `"roce": [(30,95),(25,90),(20,75),(15,60),(10,40),(5,20)]` else 5. `score_metric(name, value) -> (points, benchmark_str)`; lower-is-better metrics use ascending tables (d/e, peg). Every table documented with a comment citing the rationale.
- `pillars.py`: five builders, each returns `PillarScore` with Evidence per metric (weight-averaged, missing metrics excluded from weights and reduce pillar confidence):
  - Quality: roce_3y(.30) roe_3y(.20) fcf_margin(.20) cash_conversion(.15) accruals(.15)
  - Growth: revenue_cagr_3y(.35) profit_cagr_3y(.35) margin_trend(.15) fcf_cagr(.15)
  - Financial Strength: d/e(.30) interest_coverage(.25) net_debt_ebitda(.25) current_ratio(.10) dilution(.10)
  - Valuation: margin_of_safety(.40) peg(.20) rel_pe_discount(.20) implied_growth_gap(.20 — implied vs delivered growth)
  - Momentum: trend_state(.30) rsi_zone(.15) rel_strength(.25) dist_52w_high(.15) obv/cmf(.15)
- `engine.py`: `build_scorecard(...) -> ScoreCard`.
  - investment = quality .28 + strength .18 + growth .18 + valuation .22 + momentum .14
  - multibagger = growth .26 + quality .24 + size_runway .16 (mcap tiers: <₹5k cr high) + valuation .14 + momentum .10 + reinvestment .10 (capex/cfo & incremental ROIC)
  - **Hard gates** (cap multibagger at 35, listed in `hard_gate_failures`): accruals>0.10, ic<1.5, share dilution>8%/y, 3y FCF<0 **and** 3y NI<0.
  - confidence = 0.5·data completeness + 0.3·history years/5 + 0.2·price history/3y, per pillar and overall; verdict string from score+confidence matrix.
- [ ] TDD: threshold table lookup; pillar weight renormalization on missing metric; hard gate caps; golden scorecard on a full synthetic "compounder" fixture (expect investment ≥ 70). Commit.
