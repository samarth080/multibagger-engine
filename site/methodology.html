How the Multibagger Engine turns incomplete public data into an explainable research ranking—and where that ranking can fail.

What the score means

The Multibagger Score ranks relative business and market characteristics in the current research universe. It is not a probability, price target or guarantee of future returns. Investment Score is a complementary quality/value assessment. Confidence reflects coverage and input completeness—not the probability that a thesis succeeds. Risk summarizes identified model flags and should be read in context.

Build cadence and lineage

The Nifty Smallcap 250 screen is rebuilt weekly before the Monday NSE session. Each versioned build records its universe version, data cutoff, model version, factor configuration hash, provider versions and validation status. Static deployments show the last completed snapshot; database-backed deployments can serve the latest persisted build.

Data limitations

  • Current production fundamentals and quotes depend on unofficial Yahoo Finance data and can be delayed, stale or unavailable.
  • News matching uses RSS titles rather than article-body entity extraction; low-confidence matches are hidden.
  • Backtests retain survivorship and historical point-in-time limitations and do not establish guaranteed outcomes.
  • The canonical master is Nifty-index focused and does not yet contain complete BSE codes, listing history, SME history or corporate actions.
  • Confidence describes input coverage; it is not a forecast probability.

Financial methodology

Canonical financial facts preserve source filing, fiscal period, currency, unit, statement basis, revision and quality lineage. The first fundamental filters are annual three-year Revenue CAGR and three-year average ROCE. Missing values stay missing; zero is never treated as missing; numerators and denominators must share period, source, currency and basis.

Current static production uses a Yahoo compatibility history whose filing date and consolidated-versus-standalone basis are unavailable. Those values are labelled Ready with caveat. Verify issuer or NSE filings independently. Operating margin, leverage, coverage, cash-flow and valuation filters remain withheld until their lineage and comparability pass the documented readiness gate.

Static versus live data

Static mode reads versioned weekly JSON and remains operational without PostgreSQL. Live API mode reads the canonical database with server-side pagination. The interface never merges rows from incompatible build IDs. Quotes are a separate, failure-tolerant layer and do not determine whether rankings can render.
